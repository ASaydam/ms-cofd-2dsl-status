# MS-COFD-2DSL production status

Live progress of the MS-COFD-2DSL dataset production on the KUACC cluster:
https://asaydam.github.io/ms-cofd-2dsl-status/

- `main`: the dashboard page (`index.html`)
- `data`: `status.json` (latest status) and `history.csv` (one line per update), pushed by the cluster every
  10 minutes with a deploy key that can write only to this repository
